🎯 Lesson Objectives
🎯 By the end of this lesson, students will be able to:
  • ✅ Use can't and must to make deductions and speculate about the present.
  • ✅ Understand the difference between must (certainty) and can't (impossibility).
  • ✅ Use so…that and such…that to show cause and effect.
  • ✅ Identify the correct structure: so + adj/adv + that vs such + a + adj + noun + that.
  • ✅ Complete fill-in-the-blank sentences using the four structures accurately.
📝 Key Structures
🔵 must 🔴 can't 🟢 so…that 🟠 such…that
📖 Explanation — Part 1

🔵 Can't / Must — Deduction & Speculation

Use must when you are sure something is true (logical deduction).

Use can't when you think something is impossible.

💡 Rule Formulas
Subject
+
must / can't
+
base verb
📌 must = أنا متأكد / I'm sure it's true
📌 can't = مستحيل / It's impossible
✏️ Examples (click to reveal)
It _____ be rain. There isn't a cloud in the sky. 👁️ Show
✅ It can't be rain. → (impossible — no clouds)
It _____ be the neighbor. She's watering the plants on her balcony. 👁️ Show
✅ It must be the neighbor. → (certain — she's on the balcony)
He's laughing. He _____ be serious. 👁️ Show
✅ He can't be serious. → (impossible — he's laughing)
📖 Explanation — Part 2

🟢 So…That / Such…That — Cause & Effect

So and such make the meaning of an adjective or adverb stronger.

They are used to show cause and effect.

📐 Structure 1: so + adjective/adverb + that
so
+
adjective / adverb
+
that
He is _____ fast _____ he won the race. 👁️ Show
✅ He is so fast that he won the race.
He ran _____ fast _____ he won the race. 👁️ Show
✅ He ran so fast that he won the race.
📐 Structure 2: so + many/much + noun + that
so
+
many / much
+
noun
+
that
He has _____ many books _____ he can hardly carry them. 👁️ Show
✅ He has so many books that he can hardly carry them.
I have _____ much homework _____ I can't go out tonight. 👁️ Show
✅ I have so much homework that I can't go out tonight.
📐 Structure 3: such + a/an + adjective + noun + that
such
+
a / an
+

+

📌 such = يُستخدم قبل اسم (noun phrase) — so يُستخدم قبل صفة أو ظرف فقط
It was _____ a difficult test _____ none of the students did well. 👁️ Show
✅ It was such a difficult test that none of the students did well.

📌 Summary
📌 What We Learned Today
must
Used when you are sure something is true. (certainty / deduction)
She must be tired. (أنا متأكد أنها متعبة)
can't
Used when you think something is impossible.
He can't be serious. (مستحيل يكون جاداً)
so…that
so + adj/adv + that — OR — so + many/much + noun + that
She is so kind that everyone loves her.
such…that
such + a/an + adj + noun + that
It was such a difficult test that no one passed.
🔑 Quick Rule Reminder
🔵 so = before adjective / adverb / many / much
🟣 such = before (a/an) + adjective + noun
🟢 must = I'm sure it's true (certainty)
🔴 can't = It's impossible

📋 Answer Key — Page 237

1. They were not happy at school and got sick more often than other students.

2. You should discuss the situation carefully with your friend before you decide to live together.

3. You should talk to your potential roommate and be honest about your habits and the things that irritate you.

4. You should make rules about sharing chores, sharing food, having guests, and making noise.
